# Crunch for Mac

The native Mac app lives here. Work starts the week of 30 November 2026.

It will use the same library as the web app: the `data/` folder at the repository root
(`crunch.db`, `images/`, `backups/`). The web app's server in `../web/server` documents the
database schema (`db.ts`), the export format (`archive.ts`) and the API (`app.ts`).
